## Ingeniería de Software
La ingeniería de software es la disciplina de la ingeniería que concierne teorías, métodos y herramientas para el desarrollo profesional de software. El gasto en esta disciplina representa un alto porcentaje del PIB de los países desarrollados. 
### Enfoque profesional 
Los ingenieros de software adoptan un enfoque sistemático para llevar a cabo un trabajo. Utilizan las herramientas y técnicas necesarias para resolver el problema planteado, considerando siempre restricciones de desarrollo y los recursos disponibles. Este enfoque metódico distingue la ingeniería del simple desarrollo de código, garantizando soluciones robustas.
### Historia y Evolución de la Ingeniería de Software
La ingeniería de software surgió como respuesta a la creciente complejidad y los desafíos inherentes al desarrollo.
- **1960's:** La "crisis del software" evidenció la falta de métodos formales. 
- **1968:**  Conferencia de la OTAN: nace el término "Ingeniería de Sistemas"
- **1970's-80's:** Programación estructurada y el modelo de cascada para mayor control.
- **1990's:** Consolidación de la programación orientada a objetos.
- **2000's:** Emergen metodologías ágiles para una entrega más rápida y flexible.
- **2010-Presente:** DevOPs, cloud computing e IA transforman el desarrollo. 
## Ingeniería de Software vs Computación
- **Computación:** Concierne a la teoría y fundamentos de cualquier sistema de cómputo, sea de hardware o software. Enfoque teórico y matemático. 
- **Ingeniería de Software:** Concierne solo al desarrollo de sistemas o productos de software. Enfoque práctico y aplicado. Se entra solo en los componentes del software del sistema. 
- **Ingeniería de Sistemas:** Concierne todos los aspectos del desarrollo de sistemas basados en cómputo, incluye hardware, software y el proceso de ingeniería. Visión holística del sistema.

### Productos de software
La mayor parte del gasto del software es en productos genéricos, pero hay más esfuerzo en el desarrollo de sistemas hechos a la medida. 
##### Productos genéricos
Productos que son producidos por una organización para ser vendidos al mercado abierto: Sistemas operativos, aplicaciones de oficina, Microsoft Office, Google Chrome. 
##### Productos personalizados
Sistemas que son desarrollados bajo pedido a un desarrollador específico: Sistemas empresariales, aplicaciones corporativas, sistema bancario interno, sistema ERP empresarial.
####  Características de los Productos de software
Dependen del tipo de producto y del ambiente en que será utilizado. Los costos tienden a crecer exponencialmente si son requeridos altos niveles de alguna característica. 
- **Mantenibles:** Debe ser posible que el software evolucione.
- **Confiabilidad:** No debe causar daños físicos o económicos en el caso de fallos del sistema.
- **Eficiencia:** No debe desperdiciar los recursos del sistema.
- **Utilización adecuada:** Debe contar con una interfaz adecuada. 
### Ciclo de Vida del Software
1. **Planificación:** Define el alcance, objetivos y recursos del proyecto.
2. **Análisis de Requisitos:** Recopila y documenta las necesidades y expectativas del usuario.
3. **Diseño:** Crea la arquitectura del sistema y los componentes de software.
4. **Implementación:** Escribir el código fuente.
5. **Pruebas:** Verificar la funcionalidad y corrige para asegurar la calidad.
6. **Despliegue:** Pone el software a disposición de los usuarios finales. 
7. **Mantenimiento:** Actualiza, mejora y corrige el software después de su lanzamiento. 
8. **Retiro:** Fase final donde el software es descontinuado o reemplazado.

### Plataforma de cómputo
* **Sistemas embebidos:** Software integrado en dispositivos físicos con propósito específico.
* **Sistemas de tiempo real:** Software que debe responder dentro de límites temporales estrictos.
* **Sistemas de cómputo distribuido:** Software que opera en múltiples ordenadores conectados en red.
* **Sistema de cómputo obicuos:** Software presente en el entorno que interactúa de forma invisible.
* **Sistema de cómputo paralelo:** Ejecuta tareas en múltiples procesadores.

### Calidad de Software y Testing
- **Tipos de pruebas:** Unitarias, de integración, de sistema completo y de aceptación.
- **Automatizadas vs manuales:** Las pruebas automatizadas dan eficiencia y las manuales profundidad en la experiencia de usuario.
- **Métricas de calidad:** Indicadores clave que miden salud y robustez del software. 
- **Testing continuo:** Integración temprana y constante de pruebas.
- **Aseguramiento de calidad:** Conjunto de actividades para asegurar que se cumple con los requisitos. 
### Proceso Genérico de Software
1. **Especificación:** Establecer requerimientos.
2. **Diseño:** Producir un modelo de papel del sistema.
3. **Manufactura:** Construir el sistema.
4. **Prueba:** Verificaciones.
5. **Instalación:** Entregar el sistema al usuario.
6. **Mantenimiento:** Reparar fallos. 
### Metodologías Ágiles vs Tradicionales
**Tradicionales (cascada)**
- Enfoque secuencial.
- Requisitos definidos al inicio.
- Documentación exhaustiva.
- Cambios difíciles de implementar.
- Entrega final del proyecto. 
**Ágiles**
- Enfoque interactivo y flexible.
- Requisitos evolutivos.
- Documentación ligera.
- Adaptación continua al cambio.
- Entregas incrementales.
### Problemas en el Modelo del Proceso
- **Especificaciones incompletas:** Normalmente las especificaciones son incompletas o contienen anomalías. 
- **Distinción imprecisa:** No existe una distinción precisa entre la especificación, diseño y la manufactura.
- **Pruebas tardías:** Solo se puede probar el programa hasta que se ha producido completamente. 
- **Mantenimiento complejo:** EL software no se puede reemplazar siempre durante el mantenimiento. 
### Gestión de Proyectos de Software
- **Planificación y Estimación:** Definir alcance, establecer cronogramas y asignar los recursos necesarios. 
- **Seguimiento y Control:** Monitorear continuamente el progreso. 
- **Gestión de Riesgos:** Identificar, evaluar y desarrollar estrategias para mitigar riesgos.
- **Gestión de Equipos:** Coordinar roles, responsabilidades y fomentar una comunicación efectiva. 
- **Gestión de Calidad:** Establecer estándares y métricas de calidad. 
### Retos de la Ingeniería de Software
- **Sistema de Legados:** Sistemas antiguos que deben  ser mantenidos y mejorados. 
- **Heterogeneidad:** Sistemas que incluyen una mezcla compleja de software y hardware. 
- **Entrega:** Existe una presión incremental por una entrega. 
- **Formalidad:** Existe una gran demanda de que exista formalidad en el proceso.
