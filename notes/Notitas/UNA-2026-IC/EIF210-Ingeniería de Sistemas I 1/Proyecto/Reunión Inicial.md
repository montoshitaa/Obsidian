Backend:
- Runtime: Node.js 
- Framework: Express.js
- Lenguaje: Typescript
- DB: Mariadb
- JWT: bcryptjs (librería)
- Prisma: ORM
- node-cron: schedulers, permite que el server ejecute ciertas tareas. 
- ia ??
- docker: docker compose 
- CI: stream de implementación constante 
- Playwright: Pruebas E2E2 mock
- Jest: pruebas unitarias 

Los scripts son comandos que se pueden ejecutar con npm.
	Ejemplo: npm run dev (para ver en vivo los cambios sin tener que estar actualizando)

Para trabajar en una tarea creamos una rama feature a partir de la rama develop, al finalizar el trabajo se hace pull request para integrar con la rama develop.

Se debe documentar cada paso individualmente, es decir, cada uno se encarga de documentar lo suyo 

En la sección de project está un board para cada una de las fases, cada uno se encarga de añadir los puntos de su fase como un issue e irlas moviendo a través de los campos según su avance. Esto es importante para ir revisando el avance de todos. Pueden filtrar sus tareas en filtrar -> asignee -> me 

Vamos a tener reuniones semanales (viernes, sábado o domingo), donde cada uno expone lo que ha avanzado, responder dudas, sugerir mejoras...
